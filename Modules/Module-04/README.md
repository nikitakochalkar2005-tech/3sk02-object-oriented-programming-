# Module 04: Inheritance, Polymorphism, and Abstract Classes

## Overview
This module explains how classes can inherit features from other classes and how runtime behavior can be modeled using polymorphism and abstraction.

## Unit Included
- Unit 04 - Inheritance, Polymorphism & Abstract Classes

## Learning Outcomes
- Understand inheritance and method overriding
- Use the `super` and `final` keywords correctly
- Implement runtime polymorphism
- Design abstract class hierarchies
