# Module 01: Introduction to OOP and Programming Foundations

## Overview
This module introduces the core ideas behind object-oriented programming and the difference between procedural and object-oriented approaches.

## Unit Included
- Unit 01 - Introduction to Object Oriented Programming

## Sub-Units
- 1.1 - Introduction to OOP
- 1.2 - Need of OOP
- 1.3 - Principles of Object-Oriented Languages
- 1.4 - Abstraction and Encapsulation
- 1.5 - Inheritance and Polymorphism
- 1.6 - Procedural Language vs OOP
- 1.7 - Applications of OOP

## Learning Outcomes
- Understand the need for OOP
- Compare procedural vs object-oriented paradigms
- Explain abstraction, encapsulation, inheritance, and polymorphism
- Apply OOP thinking to problem solving
