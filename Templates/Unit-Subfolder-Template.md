# Unit Subfolder Template

Use this template for every unit folder.

## 1. Concepts

### Topic Name
- Definition
- Key points
- Important notes
- Real-world application

## 2. Notes

### Summary
- Short explanation
- Key formulas or logic
- Comparison table if needed
- Exam-oriented points

## 3. Examples

### Example Program
```java
public class Example {
    public static void main(String[] args) {
        System.out.println("Example program");
    }
}
```

### Explanation
- What the program does
- Input and output
- Important Java concepts used

## 4. Exercises

### Practice Questions
1. Write a short program to demonstrate the concept.
2. Explain the output of the sample code.
3. Modify the example for a new scenario.
4. Solve a real-world problem using the concept.

## 5. Quiz / Viva Questions
- What is the main idea of this unit?
- How does it relate to OOP principles?
- Why is this topic important in Java?
- Give one example from real life.

## 6. Learning Outcomes
- Understand the core concept
- Apply the concept in Java code
- Analyze its use in problem solving
- Evaluate correctness and output
