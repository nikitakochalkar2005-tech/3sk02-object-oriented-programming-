## Subject Description

3SK02: Object Oriented Programming is a core professional course that helps students move beyond procedural programming and develop a strong understanding of the Object-Oriented Paradigm. The course focuses on abstraction, encapsulation, inheritance, and polymorphism using the Java programming language.

Students learn Java Virtual Machine (JVM) architecture, program control flow, classes and objects, constructors, dynamic method dispatch, interfaces, custom packages, exception handling, file I/O, and GUI development using AWT and Swing.

## Course Learning Outcomes (CLOs)

After successful completion of this course, students will be able to:

- CLO1: Explain the fundamentals of Object-Oriented Programming and compare them with procedural programming.
- CLO2: Apply Java programming constructs, primitive data types, and control flow logic to write basic programs.
- CLO3: Develop modular software components using classes, objects, constructors, and static members.
- CLO4: Analyze and implement inheritance, method overriding, and abstract classes for code reusability and dynamic binding.
- CLO5: Use interfaces, packages, enumerations, and exception handling to build robust and fault-tolerant applications.
- CLO6: Handle file persistence via Java I/O, design user-friendly GUI interfaces using AWT/Swing, and apply modern secure coding principles.
